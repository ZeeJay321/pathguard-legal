# Path Guard legal pages

Public Privacy Policy and Terms of Use for store listings. This repo is **public on purpose**. The app repo is [ZeeJay321/Pathguard](https://github.com/ZeeJay321/Pathguard) (private).

After GitHub Pages is on (`main`, folder `/`):

- https://zeejay321.github.io/pathguard-legal/privacy/
- https://zeejay321.github.io/pathguard-legal/terms/

## Push / Pages

```bash
git remote add origin https://github.com/ZeeJay321/pathguard-legal.git  # once
git push -u origin main
```

Repo → **Settings → Pages** → Deploy from branch → `main` → `/` (root) → Save.

Open both URLs in a private window, then paste them into Play Console / App Store Connect.
